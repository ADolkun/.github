# Security policy

Report security problems privately, never in a public issue or pull request.

## How to report

Open the repository's **Security** tab and choose **Report a vulnerability**. This uses GitHub's private vulnerability reporting, so only the maintainer sees it. Include what is affected, how to reproduce it, and the impact you expect.

You'll hear back in the advisory once the maintainer has looked at it, and the fix is discussed there. Please allow time for a fix before disclosing publicly.

## Supported versions

Fixes go into the latest version on the default branch. Older releases aren't patched.
